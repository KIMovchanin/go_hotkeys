main.go - клей проекта.

internal/
|-> hotkeys/
|   |-> manager.go - для работы с горячими клавишами.
|   |   |-> Register - для регистрации горячей клавиши.
|   |   |-> UnregisterAll - для снятия горячих клавиш.
|   |-> parser.go - для преобразования строк из json в рабочий формат.
|   |   |-> ParseHotKey - разбивает строку типа "ctrl+alt+y" на части, преобразует в рабочий формат (hotkey.Modifier и hotkey.Key).
|-> launcher/
|   |->launcher.go - отвечает за запуск указанных адресов.
|   |   |-> Launch - инициализирует запуск.
|   |   |-> isURL - проверяет является ли преданная строка сайтом.
|   |   |-> openURL - активирует запуск сайта в браузере по умолчанию.
|   |   |-> openEXE - активирует запуск приложения.
|-> config/
|   |-> config.go - читает json данные.
|   |   |-> Load - из указываемого файлы достаёт данные в тип Bind.
